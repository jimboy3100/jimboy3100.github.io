🎮 What is Expanding Land?

Expanding Land is an independent multiplayer browser cell game with a circular map that expands and contracts. Human and server-controlled bot populations vary by arena.

▶ Play now — expanding.land

📦 Installation

  1. Install a userscript manager:
    • Firefox — Greasemonkey
    • Chrome — Tampermonkey
    • Opera — Tampermonkey
    • Safari — Tampermonkey
    • Edge — Tampermonkey
  2. Install the script: Click the green "Install this script" button above
  3. Play any IO game — the toolkit loads automatically!

⚡ Macros & Cheats (All IO Games)

  • [E] hold — Rapid Eject / Feed — machine-gun mass ejection
  • [T] — Quad Split — 4 rapid splits in one keypress
  • [S] — Freeze Cell — instantly stop your cell movement
  • [R] — Auto-Respawn — automatically respawns you after death
  • [F] — FPS Counter — live FPS overlay on screen
  • [H] — Hide/Show the control panel

🎨 Custom Skin Image Uploader (Agar.io)

When you open the skin editor on agar.io, a draggable upload panel appears automatically. Upload any image as your custom skin — three ways:

  • URL — paste an image link (ibb.co, imgur, etc.) and click Load
  • File — click "Upload From Computer" to pick an image from your PC
  • Drag & Drop — drag any image file directly onto the drop zone

Includes a circular preview, auto-centering/scaling, and tips for best results. Original concept by New Jack 🕹️.
