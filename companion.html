Legend Mod companion: stream overlay and second screen

Shows your game live: mass, rank, time alive, minimap, leaderboard, events and (optionally) chat. Nothing goes over the network: the game tab sends the data to this page inside your browser.

1. Turn it on in the game

Settings › HUD › Stream overlay / second screen (off by default). Stream overlay: include chat lines adds the chat. The button Open companion under the option opens this page.

2. Open this page on the game's own address

  • The game and this page talk over a BroadcastChannel, which only reaches pages of the same origin in the same browser.
  • Game on https://www.legendmod.ml/...: open https://www.legendmod.ml/companion.html.
  • Game on https://jimboy3100.github.io/...: open https://jimboy3100.github.io/companion.html.
  • Game on agar.io (browser extension) or inside a frame (for example expanding.land): use the Open companion button in the game. It opens this page and sends the data to that one window only. Keep both open; after reloading the game press the button again.

3. OBS

  • An OBS Browser Source is its own browser: it only receives the data if the game runs in that same browser.
  • Works everywhere: open the companion link below in a normal browser window with background green, add it to OBS with Window Capture and a Chroma Key filter.
  • bg=transparent is for a source that shares the browser with the game. demo=1 shows sample data to place the widgets.

Privacy

Stream mode (the eye button in the menu) removes your nick, skin, server address and your teammates' nicks before anything is sent; Hide my country and hide skin URL are respected too. Chat is only sent while its option is on.

Phone or another computer

Not supported yet: pairing two devices needs a WebRTC connection (and a way to exchange the connection offer), which this page does not do. The companion only works next to the game in the same browser.
